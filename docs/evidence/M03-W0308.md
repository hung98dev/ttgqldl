## 2. New and strengthened targets

Five new targets close the W0308 gaps:

- `FuzzValidateEvent` (`internal/source/fuzz_validate_test.go`): real `ValidateEvent`
  boundary; exact 500/501-byte messages, 256/257-rune identifiers, alias limits,
  unknown kinds/modes, provider/session mismatches, invalid UTF-8, control/bidi text;
  accepted events must satisfy every documented bound and rejection must be
  deterministic.
- `FuzzCrossBoundary` (`internal/ingest/fuzz_boundary_test.go`): real
  `ValidateEvent → scoped HMAC → ParseComment → Deduper`; non-comment events must be
  ignored, accepted candidates must have a valid identity and typed allowlisted action,
  and invalid events must not create a reservation.
- `FuzzDeduperStateMachine` (`internal/ingest/fuzz_state_test.go`): bounded deterministic
  operations for admit/redeliver/conflict/missing-ID/finalize/release/advance/regress/
  expire/stats; asserts cache bounds and idempotent terminal operations without sleeps.
- `FuzzBatcherOutcomes` (`internal/ingest/fuzz_queue_test.go`): bounded fake-appender
  outcomes (commit/duplicate/conflict/storage/unknown/retry-exhausted) through the real
  Batcher; asserts no false success, no duplicate+conflict result, max batch 4 in the
  target, drained queue and bounded stats.
- `FuzzReplayManifest` (`internal/source/fuzz_manifest_test.go`): bounded manifest bytes
  in an isolated temp directory; accepted manifests must have schema 1 and plain,
  unique fixture names; no fixture or production path is opened.

`FuzzParseComment` seeds were strengthened with exact 500/501-byte inputs, fullwidth
NFKC characters, combining marks, ZWJ, NUL, newlines and multiple commands. Final parser
campaign: **882,601 execs / 15 s**, no crash.

## 4. Defects found

No confirmed production defect was found in the W0301–W0307 implementation. One fuzz
**harness** invariant failed during `FuzzDeduperStateMachine`: the test tracked a pending
slice that retained already-expired reservations and asserted the slice length against
`MaxEntries`; the production cache stats remained bounded. The harness assertion was
removed (not a production behavior change) and the target then completed 247,046 execs
without failure. This is recorded as a harness false positive, not a product repair.

The campaigns did confirm the security boundaries: malformed UTF-8/control/bidi text is
rejected, exact byte/rune/grapheme limits hold, non-comment events cannot reach gameplay,
invalid identities cannot create candidates, stable IDs are deduplicated, cursor
round-trips are deterministic, replay records that decode also validate, and manifest
names cannot traverse paths.
