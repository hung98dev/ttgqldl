## 1. Repaired defect: PowerShell Unity wrapper never evaluated results

Confirmed before the fix: `tooling/unity-test.ps1` dot-sourced
`unity-results.ps1` but kept its own XML parsing, so an NUnit file with zero
tests, an all-skipped suite or inconsistent counters was reported as PASS.

Fixed in `tooling/unity-test.ps1` and mirrored in `tooling/unity-test.sh`:

1. `total == 0` → fail.
2. all-skipped / all-inconclusive (`executed <= 0`) → fail.
3. `passed == 0 && failed == 0` while total > 0 → fail.
4. inconsistent counters (`total != passed+failed+skipped+inconclusive`) → fail.
5. missing or non-integer counters → fail.
6. missing or corrupt XML → fail.
7. any failed test case → fail, naming the case.
8. non-zero Unity exit code → fail even with a green file.
9. result files are deleted before each platform run, so a stale file can never
   be reused; EditMode and PlayMode are evaluated independently.
10. PowerShell and Bash now implement the same rules.

A second real defect was found while testing: the licence branch used
`$null -ne (Select-String -Quiet)`, and `-Quiet` returns `$false` rather than
`$null`, so every missing-result run was classified BLOCKED instead of failed.
Fixed by casting the `-Quiet` result explicitly to `bool`, so the branch now returns a real boolean.

## 5. SBOM and licence inventory

`tooling/sbom` (Go, dependency-free, deterministic) emits CycloneDX 1.5 JSON and
also validates container pinning:

```
container images pinned by digest: 1
  postgres:18.6@sha256:3a426452…4b81
wrote security-reports/sbom.cdx.json (439 components)
licenses: 295 identified, 144 without metadata
```

- npm: 295 components carry licence metadata from `package-lock.json`.
- Go modules and Unity packages: no licence metadata is available offline, so
  they are marked `NOASSERTION` rather than invented (**144 components**).
- Container images must match `name:tag@sha256:<64 hex>`; an unpinned reference
  fails and an empty image list fails (vacuous check).
- Output is byte-reproducible for an unchanged checkout (test asserts it), with a
  deterministic serial number derived from the component refs.
- This is an engineering inventory, not legal approval. Unresolved licence
  question: Go/Unity components need a licence review before distribution.
