1. every canonical plan module exists;
2. every internal Markdown link and every `#heading` anchor resolves;
3. the milestone table parses, has unique ids, acyclic dependencies, and only `Mnn` / declared `GATE-*` dependencies;
4. every work package belongs to a defined milestone and is not declared twice;
5. every QA id is defined exactly once in 09 and every reference to a QA id (including `A..B` and `A/0x/0y` shorthand) resolves;
6. no obsolete parallel plan (`MASTER_PLAN.md`, `docs/v2`, `docs/v3`, `PLAN.md`) exists or is referenced outside a prohibition sentence;
7. the cross-module constant contracts (wave length, tick boundaries, fighter/guard/builder coefficients, militia falloff, boss divisor, lane split, wall thresholds, resource cap, cooldown, `ttg-rules-v1`, baseline toolchain pins) are present in their owner modules and retired values are absent;
8. a milestone marked PASS must have a PASS evidence record for **every** one of its work packages;
9. M10/M11 (external release gates) cannot leave BLOCKED without human PASS evidence;
10. the matrix's prose "Current truth" line must match the table;
11. `docs/traceability.csv` has the canonical columns, resolvable anchors, defined work packages and QA ids, and an existing evidence path per row;
12. every defined QA id is mapped by at least one requirement row.
