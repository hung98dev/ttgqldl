## Rules to resolve gaps
Each gate must have owner, evidence, decision date, change request or ADR, linked implementation tests, and explicit PASS/FAIL. No AI is authorized to assert owner approval without a real recorded approval.

## Hard technical choices vs outside-world constraints
Game rules, baseline architecture, algorithm and acceptance criteria are preselected and normative. Real external API availability, legal approvals and device-specific performance cannot truthfully be pre-guaranteed by any document. Those remain governed by explicit blocking gates.
