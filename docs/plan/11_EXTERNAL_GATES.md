# EXTERNAL GATES AND HONEST LIMITS
GATE-LIVE: proof of permitted official or expressly authorized TikTok LIVE comment access for actual account, event schema, stable ID, rate limits, reconnect/cursor, consent and current terms. No scraping workaround.
GATE-OBS: real streamer hardware and actual LIVE overlay/preview tests.
GATE-LEGAL: privacy basis, content/asset rights, provider terms and responsible operator.
GATE-HUMAN-UX: independent 5 participants, 3-second muted phone test, >=4/5 correct command+threat.
GATE-PERF: dedicated specified reference host/Unity workstation and measured FPS, latency, loss, RPO/RTO.
External gates require real accountable person and documented evidence. P0 may finish while LIVE gate BLOCKED, but human UX/asset rights/real device evidence cannot be forged. An AI can work through independent engineering tasks automatically; it cannot guarantee fully human-free TikTok LIVE production deployment.

## Accountable gate owners and minimum evidence
| Gate | Responsible approver | Required external evidence | What AI may do without approval |
|---|---|---|---|
| LIVE | actual broadcaster/account owner and permitted provider | terms/scope, API/approved source contract, account and region, sample privacy-safe event, stable user ID, reconnect semantics and date | build mock/replay and isolated authorized adapter interface; never activate real mode |
| OBS | broadcaster/operator using real setup | screenshot/recording showing commands, wall HP and boss overlay legible; capture device/OS/GPU and audio levels | generate scene, local preview and screenshots, mark real overlay BLOCKED |
| LEGAL/IP | accountable operator/content rights holder/legal reviewer | usage rights for art, audio, audience data and approved privacy notice | create original assets; document license origin without asserting legal sign-off |
| HUMAN-UX | independent real participants / operator | five anonymized observations on a muted 3s smartphone stream, at least four correct | prepare test protocol and demo; do not invent survey outcomes |
| PERF | engineering operator with actual benchmark host | command logs, hardware, CPU/RAM, DB p95, Unity FPS, 10k load, restore drill | provide load/benchmark harness and run on available machines |

External gates are not software defects and cannot be assumed true just because an AI generated a document. If the project has no provider permission, the correct executable deliverable remains a complete P0 MOCK/REPLAY product plus a BLOCKED P1 gate, not an unauthorized TikTok connector.
